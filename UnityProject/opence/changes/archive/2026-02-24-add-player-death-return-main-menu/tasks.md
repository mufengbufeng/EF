# 实施任务清单

## 1. 打通“玩家死亡 -> 返回主界面”
- [x] 1.1 为玩家死亡流程提供一次性通知（实体层到模块/流程层）。
- [x] 1.2 在 `GamePlayProcedure` 接入死亡通知并触发 `ReturnToMainMenu()`。
- [x] 1.3 为返回入口增加幂等保护，避免重复切换流程。

## 2. 统一返回主界面的退出清理
- [x] 2.1 将暂停 Back 与死亡返回复用同一退出清理收口，且清理代码仅放在 `GamePlayProcedure.OnLeave`。
- [x] 2.2 在 `GamePlayProcedure.OnLeave` 补齐清理项：`Time.timeScale`、玩法 UI（`GamePlayView`/`GameMenuView`）、摄像机堆栈、`ShutdownScope(GamePlayScope)`。
- [x] 2.3 在 `GamePlayProcedure.OnLeave` 增加玩法场景卸载步骤（基于 `ISceneManager`），失败只记录日志不阻断流程。
- [x] 2.4 清空 `GamePlayProcedure` 持有的玩法引用并解除事件订阅，保证重复进出无残留回调。

## 3. 清除局内数据
- [x] 3.1 在退出玩法时重置 `GamePlayModel` 的局内数据（至少包含 `CurrentScore`）。
- [x] 3.2 校验重新开始新局时数据从默认值起步（积分为 0）。

## 4. 验证与回归
- [x] 4.1 手工验证：玩家死亡后自动返回主界面，且只触发一次。
- [x] 4.2 手工验证：暂停 Back 返回路径仍可正常工作。
- [x] 4.3 手工验证：返回主界面后再次进入玩法，积分与局内状态无残留。
- [x] 4.4 手工验证：返回主界面后 `Game` 场景已卸载（或卸载失败时有明确日志）。
- [x] 4.5 手工验证：连续多次进出玩法，无重复回调或异常日志。
- [x] 4.6 执行 `opence validate add-player-death-return-main-menu --strict` 并通过。

## 5. Review 修复
- [x] 5.1 修复 `GamePlayProcedure` 在离开后异步进入链路继续执行的问题（增加进入会话失效保护）。
- [x] 5.2 修复退出流程的异步场景卸载竞态（按场景快照校验后再执行卸载，避免误卸载新一局场景）。

## 6. 二轮 Review 修复
- [x] 6.1 在执行场景加载和背景加载前增加会话有效性检查，避免离开后仍触发异步副作用。
